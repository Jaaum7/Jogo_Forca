# 🪢 Jogo da Forca Interativo

Uma versão moderna, dinâmica e gamificada do clássico Jogo da Forca. Esqueça o papel e a caneta: aqui, cada vitória recompensa sua habilidade e permite personalizar todo o visual do jogo!

## ✨ Funcionalidades

- **Jogabilidade Interativa:** Interface fluida, responsiva e com feedbacks visuais a cada letra escolhida.
- **Sistema de Economia:** Ganhe moedas a cada palavra descoberta e acumule saldo para investir no seu progresso.
- **Loja de Skins:** Use suas moedas para desbloquear e equipar diferentes temas e visuais exclusivos para o jogo.

## 🎮 Como Jogar

1. Inicie uma nova partida e tente adivinhar a palavra oculta escolhendo uma letra por vez.
2. Evite cometer muitos erros antes que o boneco seja completado.
3. Vença partidas para ganhar **moedas**.
4. Acesse a **Loja de Skins** no menu e gaste suas moedas como quiser para deixar o jogo com a sua cara!
